# Смета

Небольшой калькулятор предварительной стоимости сайта. HTML, CSS и JavaScript без фреймворков, установки пакетов и запросов к сторонним сервисам.

## Запуск

Откройте терминал в папке проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [калькулятор](http://127.0.0.1:8000). Остановить сервер: `Ctrl+C`.

Нужен локальный HTTP-сервер, поскольку JavaScript использует стандартные ES-модули. Открытие HTML двойным щелчком через `file://` не поддерживается. Системная тема браузера переключает светлое и тёмное оформление.

## Тарифы и формула

Все демонстрационные цены, сроки, подписи функций и значения по умолчанию находятся в объекте `TARIFFS` в `calculator.mjs`. Чистая функция `calculateEstimate({ siteType, pages, features, urgent })` возвращает `{ price, days, breakdown }` и не изменяет входные данные.

Первая страница входит в базовую цену: лендинг 45 000 ₽ / 8 дней, корпоративный сайт 90 000 ₽ / 15 дней, магазин 160 000 ₽ / 25 дней. Каждая следующая страница: 5 000 ₽ / 1 день. Лендинг всегда одностраничный; остальные типы допускают от 1 до 100 страниц.

| Функция | Доплата | Рабочие дни |
| --- | ---: | ---: |
| Форма заявки | 5 000 ₽ | 1 |
| Каталог | 25 000 ₽ | 4 |
| Онлайн-оплата | 20 000 ₽ | 3 |
| Интеграция с CRM | 15 000 ₽ | 2 |
| Две языковые версии | 20 000 ₽ | 3 |

Функции независимы. Стоимости и дни складываются. Срочность добавляет 30% к общей цене и сокращает срок на 25% с округлением вверх. Это условная предварительная модель, а не календарное планирование команды. Издержки сторонних сервисов, перевод контента и наполнение каталога в расчёт не включены.

## Проверки

Node.js 20 или новее, без установки пакетов:

```sh
node --test calculator.test.mjs
```

Проверки охватывают примеры из плана, все функции, границы страниц, округление, независимость функций и недопустимые параметры.

`browser-checks.mjs` экспортирует `runBrowserChecks(page, url)` для существующей Playwright Page. Возвращает результаты семи групп проверок: оформление мобильного итога, переключение итогов и reduced motion, пояснение ограничения лендинга и его таймер, кнопки и расчёт, ошибки и якоря, центрирование полной сметы, обе темы и читаемость. Браузерная библиотека не включена в приложение и не требуется для его запуска.

## Удобство на разных экранах

На экранах уже 768 px цена и срок видны в компактной плавающей карточке. Когда основная цена и срок полностью читаются, карточка плавно скрывается; при их уходе с экрана возвращается. При ошибке ввода аналогично учитывается основное сообщение об ошибке. Нижний отступ страницы зарезервирован постоянно, включая безопасную область устройства, поэтому переключение не сдвигает страницу. При reduced motion остаётся только затухание; клавиатурный переход переключает итог сразу.

На ПК вся смета прилипает по центру высоты окна в пределах формы. Длинная разбивка прокручивается внутри карточки и не перекрывает футер. При изменении параметров карточка возвращается к началу, чтобы новая цена была видна.

Кнопки по бокам количества страниц изменяют значение на единицу. На границах 1 и 100 недоступная кнопка отключается. У лендинга поле и «−» заблокированы; «+» показывает на 5 секунд пояснение ограничения и выделяется цветом ошибки. Повторное нажатие продлевает подсказку, смена типа и сброс сразу её убирают. При ошибочном или пустом вводе нажатие любой кнопки устанавливает одну страницу. Все подписи имеют размер от 14 px; поле числа сохраняет размер 16 px для удобного ввода на телефоне.

## Устройство

- `index.html`, `styles.css`: разметка, адаптивность, темы и доступность.
- `calculator.mjs`: единый прайс и чистая функция расчёта.
- `app.js`: связь формы и сметы.
- `assets/`: локальный Manrope с кириллицей, лицензия OFL и favicon.
- `PRODUCT.md`: согласованные продуктовые принципы.
- `WORK_LOG.md`: журнал работы и результаты проверок.

Нет аналитики, cookies, сохранения параметров или передачи введённых параметров. При перезагрузке открывается исходная конфигурация.
